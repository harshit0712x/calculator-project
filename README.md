# Calculator Web Application

A simple calculator built using:

- HTML
- Tailwind CSS
- JavaScript

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Input validation
- Division by zero handling
- Responsive UI
- Glassmorphism design

## How to Run

1. Download the project.
2. Open index.html in a browser.
